# raw (the messy inbox)

Drop anything here. A pasted chat, a photo note, a quick brain-dump, half an idea.

Nothing here is checked. Nobody stands behind it. It might be wrong, half-true, or out of
date. That is fine. This is just where things land before someone cleans them up.

You do not need to format anything. Any messy note is welcome.

Later, ask Claude to turn one of these into a real note. It will interview you
(`skills/grill.md`) and save a clean draft in `knowledge/`.
